Set up sequential AutoResearch for NanoProteinLM, then hand it over to the user. Run everything on this machine, which should be the GPU compute node, never a login node. Do not ask the user questions unless a step fails.

Settings. Take the task and program from the user's request. Use the defaults below for anything the request does not name.
- Task (<task>): tasks/171m-validation-loss.md. Alternative: tasks/171m-p-at-l.md optimizes contact P@L.
- Program (<program>): autoresearch/karpathy_ar_reward_gate.md. Alternative: autoresearch/karpathy_ar_agent_gate.md lets the agent decide what to keep.
- Workspace (<workspace>): nano-protein-autoresearch in the current folder.
- Environment: the uv environment that runs/setup.sh installs from the release's lock file.
- Data and outputs: data/ and outputs/ inside the workspace, the default DATA_ROOT and OUTPUT_ROOT, with the default 30 training shards (about 20 GB).
- Round limit (<round limit>): the full 72-round allowance.
- tmux session (<session>): nanoprotein-ar
- Search agent (<agent>): the same coding agent as you, started in its mode for long unattended runs, for example `codex --approve-for-me` for Codex. If you do not know that command for your agent, ask the user.

Steps:

A. Check that nvidia-smi shows four matching H100 or L40S GPUs and that tmux, git and npx (Node.js) are installed. If uv is missing or not within >=0.11.31,<0.12, install uv 0.11.31 with its official installer (https://astral.sh/uv/0.11.31/install.sh) and tell the user. If anything else is missing, tell the user and stop.

B. Install the loop skill for the search agent, naming it with -a (for example codex or claude-code):
   npx skills add Lumin-Science/Nano-AutoResearch-Skills --skill ar-loop-n-sleep -g -a <agent> -y

C. Clone only the release commit into the workspace and remove the remote:
   git clone --depth 1 --single-branch --no-tags --branch autoresearch-v0 https://github.com/Lumin-Science/Nano-ProteinLM.git <workspace>
   cd <workspace> && git remote remove origin
   If HTTPS asks for credentials, use git@github.com:Lumin-Science/Nano-ProteinLM.git instead.

D. Run `bash runs/setup.sh` in the workspace and let it finish; it installs the environment and downloads and verifies the data. Only if the user's request names other data or output folders, first write DATA_ROOT=<path> and OUTPUT_ROOT=<path> to .env in the workspace.

E. Start a detached tmux session named <session> in the workspace, running the search agent. If the agent asks to trust the folder, accept. If it asks for anything else, such as signing in, stop and tell the user. Once its input box is ready, type this prompt into it with `tmux send-keys -l`, single-quoted, and do not press Enter:
   Use the ar-loop-n-sleep skill. Read <task> and <program>. Use the allocated four GPUs. Run sequential AutoResearch for <round limit>, following the program, then stop without another wakeup.

F. Tell the user to run `tmux attach -t <session>` and press Enter to start the search. Do not start the research yourself.
